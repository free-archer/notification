# Информатор рабочих встреч

Локальный Linux-информатор, который напоминает о рабочих встречах **за 15 минут, 5 минут, 1 минуту и в момент начала**. Работает только в локальной графической сессии (GNOME/Wayland) и не зависит от браузера, Яндекс Календаря или интернета.

Предназначен для случая, когда встречи пропускаются из-за того, что календарь открыт в браузере, браузерное сообщение не видно или пользователь подключён по RDP.

## Как это работает

- Фоновый Python-процесс на GTK читает локальное текстовое расписание `events.txt`.
- Для каждой встречи считает четыре точки срабатывания и показывает **обязательное окно** поверх остальных окон с **повторяющимся системным звуком**, пока не нажато «Понятно».
- При изменении файла расписание перечитывается **без перезапуска**.
- Запускается автоматически при входе в локальную графическую сессию через `systemd --user`.

## Установка

Уже настроено в этом репозитории. Ключевые точки:

- Расписание: `~/.local/share/meeting-informer/events.txt`
- Служба: `~/.config/systemd/user/meeting-informer.service` (включена автозапуском)
- Скилл Pi: `~/.agents/skills/meeting-informer/SKILL.md`

Проверить/перезапустить службу:

```bash
systemctl --user restart meeting-informer.service
systemctl --user status meeting-informer.service
```

Журнал:

```bash
journalctl --user -u meeting-informer -f
```

## Формат расписания

Одна встреча — одна строка:

```text
YYYY-MM-DD HH:MM | Название встречи
```

Пример:

```text
2026-08-26 14:30 | Планёрка отдела
2026-08-27 09:00 | Встреча с заказчиком
```

- Время — локальное время Linux.
- Пустые строки и строки, начинающиеся с `#`, игнорируются.
- Ошибочная строка не ломает приложение — фиксируется в журнале.
- Поддерживаются только **разовые** события.

## Добавление встреч через Pi-скилл

Приложите скриншот Яндекс Календаря и попросите занести встречи. Скилл распознает дату, время и название, подготовит строки и обновит файл через валидатор:

```bash
printf '%s\n' "2026-08-26 14:30 | Планёрка отдела" | ~/bin/meeting-informer-update
```

Валидатор:
- не создаёт точных дубликатов;
- сохраняет существующие строки;
- записывает атомарно (информатор не прочитает частично записанный файл);
- сообщает добавленные, пропущенные и ошибочные события.

## Ручное добавление

Просто отредактируйте `events.txt` — информатор подхватит изменения за секунды.

## Разработка и тесты

```bash
python3 -m unittest discover -s tests
```

Файлы:

- `meeting_informer/parser.py` — разбор `events.txt`
- `meeting_informer/scheduler.py` — точки срабатывания и отбор «созревших» напоминаний
- `meeting_informer/sound.py` — повторяемый системный звук
- `meeting_informer/app.py` — GTK-цикл и обязательные окна
- `meeting_informer/updater.py` — CLI-валидатор обновления (для скилла)
- `bin/meeting-informer` — лаунчер, подхватывающий окружение графической сессии
- `systemd/meeting-informer.service` — пользовательская служба

## Ограничения

- Работает **только в локальной графической сессии** Linux. RDP не используется для показа окон и звука.
- Только разовые события; повторяющиеся встречи и длительность в первой версии не поддерживаются.
- Тестовый сигнал удобно проверить, добавив событие на ближайшую минуту.

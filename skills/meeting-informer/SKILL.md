# Информатор встреч: импорт из скриншота

Назначение — распознать встречи на скриншоте Яндекс Календаря и добавить их в расписание локального информатора встреч (`~/.local/share/meeting-informer/events.txt`). Информатор затем напомнит за 15 минут, 5 минут, 1 минуту и в момент начала.

## Формат записи

В файле одна встреча занимает одну строку:

```text
YYYY-MM-DD HH:MM | Название встречи
```

Время — локальное время Linux. Пример:

```text
2026-08-26 14:30 | Планёрка отдела
2026-08-27 09:00 | Встреча с заказчиком
```

## Шаги

1. **Прочитай скриншот.** Просмотри прикреплённое изображение календаря (обычно недельная или дневная сетка Яндекс Календаря).

2. **Найди разовые встречи.** Определи видимые встречи. Повторяющиеся (серии) в первой версии не поддерживаются — их пропускай с пометкой.

3. **Определи дату, время и название** для каждой встречи:
   - год — из текущей даты или подписей сетки календаря;
   - дата и время — из ячеек сетки;
   - название — из текста события.

4. **Сформируй строку** `YYYY-MM-DD HH:MM | Название`.

5. **Проверь уверенность.** Если год, дату, время или название определить уверенно нельзя — **не угадывай**. Такую встречу не записывай и отметь в отчёте как ошибку.

6. **Передай строки в валидатор.** Отправь строки по одной на строку в stdin команды `/home/archer/bin/meeting-informer-update`:

   ```bash
   printf '%s\n' \
     "2026-08-26 14:30 | Планёрка отдела" \
     "2026-08-27 09:00 | Встреча с заказчиком" \
     | /home/archer/bin/meeting-informer-update
   ```

   Если строк много — используй временный файл и перенаправь stdin:

   ```bash
   cat /tmp/meetings.txt | /home/archer/bin/meeting-informer-update
   ```

7. **Покажи отчёт.** Валидатор вернёт сводку: «Добавлено», «Пропущено (дубликат)», «Ошибки». Перескажи пользователю результат: какие встречи добавлены, какие уже были, какие вызвали сомнение.

## Правила

- Точный дубликат по тройке «дата, время, название» не добавляется повторно — валидатор его отсекает. Повторная обработка того же скриншота безопасна.
- Существующие строки файла сохраняются как есть.
- Запись выполняется атомарно — информатор не прочитает частично записанный файл.
- Сомнительные данные не записывай молча; фиксируй их в отчёте.
